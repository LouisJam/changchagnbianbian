# 肠肠扁扁宠咖 - 宠物咖啡馆官网

基于 Vue3 + Vite + Animal-Island-Vue 组件库开发的萌系宠物咖啡馆官方网站，包含店铺介绍、员工展示、菜单页面、留言墙等完整功能模块。

## ✨ 项目介绍
肠肠扁扁宠咖是一家温馨治愈的人宠社交空间，主打可爱治愈的视觉风格与轻松的互动体验。
本项目为官网前端展示页面，用于展示店铺信息、宠物员工、饮品菜单及用户互动功能。

## 🛠 技术栈
- Vue 3
- Vite
- Vue Router
- Animal-Island-Vue 组件库
- CSS3 / 响应式布局

## 📁 功能页面
- 首页 - 店铺介绍与导航
- 员工介绍页 - 宠物员工展示
- 饮品甜点页 - 菜单展示
- 便利贴留言墙 - 互动留言功能
- 表情包墙 - 趣味图片展示
- 最佳员工榜 - 人气评选展示

## 🚀 本地运行
```bash
# 安装依赖
npm install

# 启动开发服务
npm run dev

# 构建生产版本
npm run build
