# 🐶 肠肠扁扁宠咖官网
![Vue3](https://img.shields.io/badge/Vue3-4FC08D?logo=vue.js&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![响应式](https://img.shields.io/badge/响应式布局-FFD166?logo=responsive&logoColor=black)

基于 Vue3 + Vite + Animal-Island-Vue 开发的萌系宠物咖啡馆官网，主打治愈可爱的视觉风格，适配PC+移动端。

## 📋 功能模块
- 🏠 首页：店铺核心信息 + 导航入口
- 👨‍💼 员工页：宠物员工展示 + 品字形滚动布局
- ☕ 菜单页：饮品/甜品展示 + 分类筛选
- ✏️ 留言墙：用户互动留言 + 便利贴样式
- 😜 表情包墙：趣味图片展示
- 🏆 最佳员工榜：人气评选展示

## 🎨 设计风格
- 主色调：暖黄 `#FFD166` / 浅咖 `#F5E6D3`
- 字体规范：华康海报体（大标题）、华康圆体（小标题）、华康新综艺体（正文）
- 视觉风格：治愈、可爱、宠物主题、柔和圆角

## 🚀 快速启动
```bash
# 安装依赖
npm install

# 本地开发
npm run dev

# 生产构建
npm run build

## 📁 项目结构

## 📝 使用说明
- 本项目为纯前端展示页面，无后端接口，数据均为本地模拟。
- 适合作为宠物主题、咖啡馆、萌系风格的官网参考项目。
